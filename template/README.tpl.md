1. **真的免费** —— 不用先付费再返现、不用邀人解锁、不用等首月特价；
2. **能长期用** —— 不是七天试用，不是一次性体验金；
3. **现在还有效** —— 每条都带「最后确认」日期，失效就标失效，不删了装死。

## 怎么加一条

改 `data/` 下对应分类的 JSON，跑 `python3 tools/build.py`，README 自动重排。必填四项：`name` `url` `what` `gate`。

```json
{
  "name": "示例服务",
  "url": "https://example.com",
  "what": "每月 100 万 token、5 个并发",
  "gate": "邮箱",
  "gotcha": "只算新用户；超量直接停服不扣费",
  "checked": "2026-10-25"
}
```

`status` 可选，填 `dead` 表示已失效（行会置灰删除线留下来当墓碑）。
