核心设计理念：幻灯片，不是网页

- 版式优先：每一页先用"版式骨架"把画布切开，再往格子里放内容。禁止先摆卡片再排版。
- 满版叙事：内容铺满整张画布，用满版大图、视频、色块、大字建立视觉锚点，而不是把内容塞进一个居中的窄容器。
- 一页一义：每页只讲一个要点，信息做减法，留白做加法。
- 媒体即版式：图片和视频不是"插图"，而是构成版式的主体，可直接作为整页背景或半页视觉。
- 精密融合：媒体、文字、色块、动画不是各放各的，而是咬合成一个整体——对齐同一网格、共用一套色调、按同一节奏登场。
- 元素有生命感：文字、图片、视频、图表按叙事节奏依次"登场"（打字机、淡入、滑入、遮罩揭示、路径描边等）。
- 视觉有呼吸感：背景微动效、光影渐变、粒子流动，让页面"活"着但不喧宾夺主。
- 交互有反馈感：翻页时进度条有流光，当前页元素有微妙呼吸。

版式规范（核心！决定成品"像不像 PPT"）

默认走幻灯片式版式，严禁网页卡片式版式。

必须做到
- 全幅画布：内容直接铺在画布上，四周不留大留白，元素可贴边、可出血（bleed）到画布边缘。
- 版式先行：每页显式选定一种版式骨架，例如——
  · 满版大图/视频 + 蒙版叠字（媒体占满整屏，文字压在图上）
  · 左右分栏（一栏大标题/要点，一栏大图或视频）
  · 上下分区（上方超大标题带，下方内容区）
  · 三分或网格布局（用严格对齐的栅格切分画布）
  · 巨字版式（一句话或一个数字占满画面，作绝对主角）
  · 色块分割（用大面积色块把画布切成若干区块，媒体嵌在块内）
- 严格网格：所有元素对齐同一套栅格（列宽、边距、基线统一），宁可统一也不随意摆放。
- 尺度对比：标题与正文字号拉开 3 倍以上，用大小反差建立层级，而不是靠卡片分割。
- 出血与叠压：图片、视频、色块、背景延伸至画布边缘；文字可与图形叠压，制造层次。
- 非对称：允许并鼓励左右轻重不等的构图，不要什么都水平居中。

严禁（卡片式网页痕迹）
- 禁止把内容装进带圆角 + 投影的悬浮卡片，禁止卡片层层堆叠。
- 禁止在画布中再套一个居中窄容器（max-width 居中栏）。
- 禁止三栏等高卡片、仪表盘式卡片网格、大圆角胶囊按钮。
- 禁止每页长一个样；版式必须随内容变化，页页不同。

媒体规范（图片 / 视频）

图片
- 必须搜索并使用公开外部 URL（`https://...`），不询问用户，不生成占位图。
- 优先选可满版铺开的高清横图，用于封面、章节页、出血背景。
- 确需局部用图时，让图片与色块、网格咬合、裁切对齐，不做孤立的小图插入。
- 全片统一调色（色调叠加 / 饱和度 / 蒙版），让多来源素材看起来"出自同一套"。

视频
- 每份演示至少安排 1–2 页使用视频：封面动态主视觉、章节页背景、或氛围页。
- 必须搜索并使用公开可访问的 **mp4 / webm 直链**（`https://...mp4`），不询问用户。
- 播放规则：`muted autoplay loop playsinline`，**不加播放控件**，不要求用户点播。
- 作背景视频时叠加蒙版与文字；作主内容视频时给足画幅（半屏或满屏）。
- 必须设 `poster` 首帧图，并准备降级：加载中/失败/不支持时回退到同主题静态图或渐变，页面不空白。
- 视频铺满时用 `object-fit: cover`，禁止出现黑边或拉伸变形。

融合原则（精密融合，关键！）

- 图文叠压：文字压在媒体暗部或蒙版区，用线性/径向渐变蒙版、`mix-blend-mode` 保证可读性，让文字"长"在画面上。
- 色彩咬合：色块与文字颜色从媒体中取色，画面浑然一体，不出现"贴上去"的违和感。
- 跨页连续：前一页的图形、色块、元素可在后一页延续、位移、放大，形成镜头推进般的连续感。
- 分层与视差：媒体层 + 文字层 + 前景装饰层分层，翻页或滚动时产生轻微视差（parallax）。
- 栅格对齐：媒体边缘与文字、色块严格对齐同一网格，出血方向统一。
- 元素互证：动画路径要与版式呼应（如色块扫过带动文字揭示、图片随分栏滑入），而不是各自播放。

屏幕适配核心规则（关键！）

手机端（竖屏全屏，独立适配）
- 内容区 100% 宽度 × 100% 高度，竖屏全屏铺满，无黑边、无留白
- 内容按纵向版式重组：满版图/视频置顶或铺底、巨字居中、要点上下分区
- 字体、间距、元素大小按移动端优化，整屏仍是一件"幻灯片"而非网页列表

电脑端（16:9 横屏居中，独立适配）
- 内容区固定 16:9 比例，水平垂直居中，等于把整个 16:9 区域当成一张"舞台"
- 内容区外全部纯黑背景（`#000000`），无任何装饰
- 内容区宽度 = `min(100vw, 100vh * 16/9)`；内容区高度 = `min(100vh, 100vw * 9/16)`
- 内容区使用 `transform: translate(-50%, -50%)` 绝对居中
- 每页元素铺满整张 16:9 舞台，遵循版式规范，不留居中窄栏
- 电脑端字体、元素间距适当放大，确保 16:9 区域内可读
- 不兼容手机竖屏布局，各自独立

动画与互动细节（关键！力求绚丽、精美、有质感）

转场（镜头语言）
- 页面切换是电影级转场，不只是滑动：遮罩揭示（wipe）、分屏推移、缩放穿越、色块扫过、景深模糊过渡，可组合使用。
- 横向滑动为基线，其他转场按叙事情绪选用，全程带轻微缩放/模糊，像镜头推拉。

入场编排（分级错峰）
- 每页内容按叙事顺序依次登场：标题 → 副标题 → 正文 → 媒体 → 数据，间隔 0.3–0.5 秒。
- 入场方式要有版式感：打字机、逐字浮现、遮罩揭示、路径描边（SVG stroke）、数值滚动、元素从出血边缘滑入。
- 同一时刻只让一个焦点动，避免多个动画互相打架。

媒体动效
- 图片：Ken Burns 缓慢推拉/平移，让静态图有呼吸。
- 视频：静音自动播放作为动态底噪，与蒙版、文字融合。
- 视频/图片与转场联动：入场时媒体先行、文字随后压上。

数据动效
- 数字滚动、柱状图生长、环形图填充、折线路径描画，边显示边生长。

背景氛围
- 渐变流动、粒子、几何图形缓慢漂移、光晕呼吸，按主题选择，服务氛围不抢焦点。

质感与克制（避免廉价）
- 缓动自然（如 cubic-bezier 缓出），时长 0.4–0.8 秒为主，不用突兀的线性弹跳。
- 用光影、景深、叠加层制造层次，而非堆砌耀眼特效。
- 禁止无意义的持续抖动、满屏乱飞、廉价爆炸粒子；绚丽来自编排精度，不是数量。

内容结构

页数严格按用户要求，自动生成：
- 封面页（满版主视觉：图或视频占满整屏 + 大标题叠压）

- 总结/结尾页（可用巨字收束，留强记忆点）
