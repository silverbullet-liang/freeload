# 视觉主题（6 套）

每套是一组 CSS 变量 + 一条排版规则。切换只改 `data-theme`，不动内容结构。
选哪套由题材决定，不要为了好看硬套。

| key | 名称 | 适合 | 底色 | 强调色 | 字体气质 |
|---|---|---|---|---|---|
| `noir` | 暗场点阵 | 技术/算法/数据、夜间观看 | `#0b0c11` | `#6630F8` | 超粗无衬线，负字距 |
| `paper` | 暖纸 | 人文/产品/叙事、长文改编 | `#f6f1e7` | `#b4472d` | 衬线标题 + 无衬线正文 |
| `swiss` | 瑞士白 | 方法论/对比/流程 | `#ffffff` | `#d0021b` | 无衬线，左对齐，大留白 |
| `terminal` | 终端 | 代码/协议/调试 | `#0a0f0a` | `#39d353` | 等宽，全站单色 |
| `blueprint` | 蓝图 | 架构/系统设计 | `#0f1b3d` | `#7fb2ff` | 无衬线 + 网格线稿 |
| `soft` | 柔光 | 科普/教育/亲子 | `#f2f4f8` | `#3b6ef0` | 圆体/常规，卡片圆角 |

## 变量契约

模板只认这 12 个变量，主题只需给它们赋值：

```css
--bg        画布底色
--fg        主文字
--muted     次级文字
--accent    强调色（关键数字、进度填充）
--accent-2  次级强调（高光、渐变末端）
--line      分隔线 / 描边
--grid      背景纹理颜色（点阵/网格线）
--font      标题字体栈
--font-body 正文字体栈
--mono      等宽字体栈
--radius    卡片圆角（0 表示硬边）
--shadow    卡片阴影（暗色主题用 none）
```

## 各主题的背景纹理

- `noir`：`radial-gradient(circle, var(--grid) 1px, transparent 1px)`，26px 栅格，顶部椭圆遮罩淡出。
- `paper`：细颗粒噪点（`repeating-linear-gradient` 45° 交错，透明度 ≤0.03），避免纯色的塑料感。
- `swiss`：无纹理。靠巨大留白与硬分割线。
- `terminal`：暗部扫描线（`repeating-linear-gradient(0deg, ...)`，间距 4px，透明度 0.04）。
- `blueprint`：40px 网格（横竖各一条 1px 线，透明度 0.10）+ 四角小十字。
- `soft`：无纹理，用大圆角卡片与柔和阴影分层。

## 排版规则（所有主题通用）

1. 标题字号 ≥ 44px（720p 基准），最多两行；超过就拆镜头，不要缩字号。
2. 正文与标题的字号比约 1:2.2。正文行高 1.6–1.75。
3. 每镜一个主角：一个标题 + 一行支撑信息 + 一个图形。三样以上就拆。
4. 数字与单位单独成行时，数字用强调色，单位回落 `--muted`。
5. 字幕固定在画面下 1/8 处，与画面之间留 ≥12px 空隙，不要压图形。
6. 暗色主题的文字必须带 1px 描边或外发光（否则在压缩后会糊）；浅色主题不要描边。

## 主题与内容的一致性

- 讲算法/数据 → `noir` 或 `blueprint`
- 讲代码/协议 → `terminal`
- 讲观点/对比/方法论 → `swiss`
- 讲产品/故事/人 → `paper` 或 `soft`
- 同一支片只用一个主题；章节之间不换肤（换肤会打断观看节奏）
